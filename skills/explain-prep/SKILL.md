# 제출 전 설명 점검

과제 안내와 README, 변경된 코드, 실제 실행·테스트 기록을 확인한다. 확인 질문이 시작되기 전에만 사용한다.

1. 핵심 동작을 `사용자 행동 → 관찰한 결과`로 최대 3개 정리한다. 각 결과에 실제 확인 방법을 붙인다.
2. AI가 제안한 내용 중 채택·수정·거절한 결정과 그 이유를 작업 기록에서 찾는다. 판단이 기록되지 않았다면 사용자에게 확인한다.
3. 요구사항별로 검증됨·부분 검증·미검증을 구분하고, 남은 한계를 짧게 적는다.
4. 사용자가 직접 설명할 수 있도록 구현과 판단에 관한 예상 질문을 최대 5개 제시한다. 답변을 암기시키기보다 관련 코드와 검증 증거를 짚어 준다.

실행하지 않은 테스트나 존재하지 않는 판단을 사실처럼 쓰지 않는다. 제출 후 AI 사용이 금지된 문항에서는 이 Skill을 사용하지 않는다.
