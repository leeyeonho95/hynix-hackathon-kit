# 제출 전 점검 (마감 15~20분 전 시작)

## 1. 깨끗한 실행
- 의존성 설치부터 실행까지 README 명령을 그대로 따라 실행해 본다.
- 포트, 환경변수, 시드 데이터 명령이 README에 모두 있는지 확인한다.

## 2. README 구성 (짧게)
```
# 서비스 이름 — 한 줄 설명
## 해결하는 문제 (누구의 무엇)
## 실행 방법
## 주요 기능 (인수 기준과 대응)
## 구조 (EXPLAIN.md 링크)
## 하지 않은 것 / 한계
```

## 3. 요구사항 충족표
REQUIREMENTS.md의 Must/Should 각각에 대해 완료/부분/미완과 확인 방법을 표로 정리한다. 미완은 숨기지 않고 이유를 적는다.

## 4. 정리
- 쓰지 않는 파일, 주석 처리된 큰 코드 덩어리, 디버그 print 제거
- 비밀값·토큰·개인정보가 코드에 없는지 grep: `grep -rniE "api[_-]?key|secret|password|token" --exclude-dir=node_modules .`
- 스크린샷 등 임시 파일 정리

## 5. 설명 준비
- `decision-log` skill로 EXPLAIN.md를 완성하고 사용자에게 핵심 질문 5개를 낸다.
- 사용자가 직접 설명할 수 없는 코드가 있으면 그 부분을 짧게 짚어 준다.
